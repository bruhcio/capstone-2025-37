# 1. 프로젝트 소개

프로젝트
본 프로젝트는 대학원생의 고된 연구 생활을 유쾌하게 재해석한 턴제 슬롯 시뮬레이션 게임입니다.플레이어는 각기 다른 학과(컴퓨터공학과, 생명학과, 연극영화과 등)의 대학원생이 되어,매 턴 슬롯을 돌려 연구 포인트를 얻고, 다양한 아이템과 심볼의 시너지로 전략적인 성장을 도모해야 합니다.

기술적 특징

2D 도트 그래픽 기반 UI/UX그래픽 리소스가 제한된 상황에서 최대한 직관적이고 경쾌한 게임성을 구현

동적 심볼-아이템 상호작용 엔진각 학과별 전용 심볼과 아이템이 고유의 규칙과 효과를 가지며,조건에 따른 시너지 발생 로직은 CSV 기반 동적 파싱으로 유지보수 및 확장 가능성 확보

AI 기반 리소스 파이프라인캐릭터 및 배경 리소스 일부는 ChatGPT-4o 기반 생성 시스템을 도입하여 생성반복적 리소스 제작 부담을 줄이고, 개발 효율성을 극대화

스테이지 기반 난이도 시스템Stage 1~25까지 존재하며, 매 턴마다 납부해야 할 연구 포인트가 기하급수적으로 증가특정 층부터는 디버프 심볼, 전용 페널티, 심볼 슬롯 제한 등 다양한 도전이 존재

모바일 중심 설계단시간 플레이 중심 UX를 반영하여 Google Play 기반 실제 배포를 목표로 설계

## Markdown을 사용하여 내용꾸미기

Markdown은 작문을 스타일링하기위한 가볍고 사용하기 쉬운 구문입니다. 여기에는 다음을위한 규칙이 포함됩니다.

```markdown
Syntax highlighted code block

# Header 1
## Header 2
### Header 3

- Bulleted
- List

1. Numbered
2. List

**Bold** and _Italic_ and `Code` text

[Link](url) and ![Image](src)
```

자세한 내용은 [GitHub Flavored Markdown](https://guides.github.com/features/mastering-markdown/).
